Describe que hacen los siguientes comandos de git, escribe su descripcion al frente en una sola linea.

git status: Este comando se usa para obtener el estado actual del repositorio

git clone: Este comando se usa para clonar repositorios

git pull: Descarga los cambios mas recientes de un repositorio remoto y los integra inmediatamente a tu rama local

git checkout: Cambiar de rama y actualizar el directorio local con los archivos de esa rama

git log: Muestra un historial de cambios que a tenido el repositorio

git branch: Se puede usar para crear, eliminar y dar una lista de las ramas que posee el repositorio

git add: Agregar los cambios que se hicieron alistandolos para el siguiente commit que los subira

git commit: Agrega los cambios previamente preparados en una instancia para el repositorio

git push: sube los commits que se ha echo en el commit local para actualizar el repositorio de github

git merge: Se usa para unir dos ramas la ramas que se hicieron de la principal
